# 统一响应格式

业务视图使用 `ApiResponse` 返回统一 JSON 结构；DRF 全局异常处理器也会尽量保持相同结构。

## 响应结构

```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | integer | 与 HTTP 状态一致的业务状态码 |
| `message` | string | 操作结果或稳定错误类别 |
| `data` | any/null | 业务数据、字段错误或 `null` |

## 视图中的用法

```python
from mctp_api.mctp_api_core.response import ApiResponse

return ApiResponse.success(data={"key": "value"})
return ApiResponse.created(data=serializer.data)
return ApiResponse.error(message="validation error", code=400, status=400)
return ApiResponse.not_found()
return ApiResponse.unauthorized()
return ApiResponse.forbidden()
```

`ApiResponse.error()` 的 `code` 和 `status` 应保持一致。对于 serializer 校验错误，将 `serializer.errors` 传给 `data`。

## 认证失败示例

```json
{
    "code": 401,
    "message": "authentication required",
    "data": null
}
```
