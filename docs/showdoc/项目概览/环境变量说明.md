# 环境变量说明

项目通过 `.env`（本地开发）或部署平台环境变量管理配置。`.env` 已被 Git 忽略，不应提交。

## 配置方式

```powershell
Copy-Item .env.example .env
```

macOS/Linux:

```bash
cp .env.example .env
```

## Django 基础配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `SECRET_KEY` | 生产必填 | 开发模式使用临时值 | `DEBUG=False` 时必须设置 |
| `DEBUG` | 否 | `False` | 生产环境保持 `False` |
| `ALLOWED_HOSTS` | 否 | `localhost,127.0.0.1,.onrender.com` | 多个主机名用逗号分隔 |
| `CORS_ALLOWED_ORIGINS` | 否 | `http://localhost:5173` | 允许的前端 Origin，多个用逗号分隔 |

## Microsoft OAuth

启用 Microsoft 登录时需要设置 `MS_CLIENT_ID`、`MS_CLIENT_SECRET` 和 `MS_TOKEN_FERNET_KEY`。`MS_REDIRECT_URI` 与 `FRONTEND_OAUTH_CALLBACK` 有本地开发默认值，但生产环境应显式覆盖。

| 变量名 | 说明 |
|--------|------|
| `MS_CLIENT_ID` | Azure 应用程序（客户端）ID |
| `MS_CLIENT_SECRET` | Azure 应用密钥值 |
| `MS_REDIRECT_URI` | Microsoft 回调地址，必须与 Azure 配置完全一致 |
| `FRONTEND_OAUTH_CALLBACK` | OAuth 成功或失败后跳转的前端地址 |
| `MS_TOKEN_FERNET_KEY` | 加密存储 Microsoft refresh token 的 Fernet 密钥 |

配置步骤见[Microsoft OAuth 配置指南](../../microsoft-oauth-setup.md)。

## ShowDoc（可选）

| 变量名 | 说明 |
|--------|------|
| `SHOWDOC_URL` | ShowDoc 服务地址 |
| `SHOWDOC_API_KEY` | ShowDoc API Key |
| `SHOWDOC_API_TOKEN` | ShowDoc API Token |

## 生成密钥

```powershell
uv run python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
uv run python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## 安全注意事项

- 生产密钥只通过部署平台的 secret/environment 管理。
- 不要提交 `.env`、OAuth secret、Fernet key 或 JWT。
- 修改 OAuth 回调地址后，同时更新 Azure 应用注册和 `MS_REDIRECT_URI`。
